# Instructions

Record the why behind significant decisions as an ADR in `docs/adr/` (one file per decision, numbered). README.md describes what the project is and how to use it.

After any changes to the config, check README.md and update it if the changes affect documented structure, keymaps, install instructions, or usage.

After config changes, run `bash tests/test_formatting.sh` and `bash tests/test_treesitter.sh`. Done means both pass.
